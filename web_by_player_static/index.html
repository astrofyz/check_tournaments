Tournament check

Uses GET /players/{id}/tournaments/ plus seed lookups and intersections. One player id per line. Each tournament line: if it is digits only, it is a tournament id; otherwise the API is queried by name after stripping leading punctuation. If the full line matches nothing but there are several words, each word is searched and results are intersected (tournaments whose names match every word as a substring).

Open this folder with a local static server (for example python3 -m http.server inside web_by_player_static) so the browser can load app.js. If requests to the API fail with a network or CORS error, use the FastAPI app instead (same machine proxies the API).
