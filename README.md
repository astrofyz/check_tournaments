# Проверка заигранности турниров

Сервис помогает проверить, **заиграны ли турниры** кем-то из указанных игроков.

## Как указать турниры

- **По id** — один числовой id на строку.
- **По названию** — поиск по базе рейтинга (возможны неоднозначности).
- **Массовая загрузка** — все доступные онлайны/асинхроны на ближайшее воскресенье; можно задать интервал сложности (`difficultyForecast`).

Список для массовой загрузки берётся с stalnuhhin. Если сайт отвечает **403**, приложение использует локальный снимок `tours_snapshot.json` (обновляется вместе с кэшем в GitHub Actions). После успешного workflow: `git pull`.

## Пересечения (Check intersections)

- **Выкл.** — только турниры из списка.
- **Вкл.** — также турниры с тем же пакетом вопросов. Кэш: `intersections_cache.json`.

После массовой загрузки пересечения по умолчанию выключены.

## Обновление кэшей

```bash
python build_intersections_cache.py \
  -o data/intersections_cache.json \
  --tours-snapshot data/tours_snapshot.json
```

Или workflow **Build intersections cache** (пятница ~23:00 Париж / вручную).
