# Проверка заигранности турниров

Сервис помогает проверить, **заиграны ли турниры** кем-то из указанных игроков — то есть участвовал ли уже кто-то из списка в этих турнирах (или в связанных с ними по вопросам).

## Как указать турниры

- **По id** — один числовой id турнира на строку.
- **По названию (подстроке)** — выполняется поиск по базе рейтинга. Возможны неоднозначные совпадения.
- **Массовая загрузка** — кнопка загрузки всех доступных **онлайнов / асинхронов на ближайшее воскресенье** (данные планировщика https://chgk.stalnuhhin.ee). Поле турниров заполняется списком id; при необходимости список можно править вручную.

При массовой загрузке можно задать **интервал желаемой сложности** (`difficultyForecast`: минимум и/или максимум). Турниры без прогноза сложности в такой фильтр не попадают.

## Пересечения (Check intersections)

- **Выключено** — учитываются только турниры из введённого списка.
- **Включено** — дополнительно учитываются турниры, которые **пересекаются по пакету вопросов** с указанными. Если игрок уже играл такой «связанный» турнир, исходный тоже считается заигранным.

После массовой загрузки пересечения по умолчанию **выключаются** (быстрее для длинного списка). Их можно снова включить вручную.

## Кэш пересечений

Файл `intersections_cache.json` ускоряет проверку при включённых пересечениях: заранее собранные связи seed → пересечения. Обновляется еженедельно (пятница вечером по Парижу) или локально:

```bash
python build_intersections_cache.py -o data/intersections_cache.json
```
